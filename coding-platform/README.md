# Educational Coding Platform

Платформа для проведения самостоятельных работ по информатике с защитой от списывания и мониторингом активности учеников.

## Возможности

### Для учителей:
- Создание заданий с временем выполнения
- Мониторинг активности учеников в реальном времени
- Проверка работ с удобным интерфейсом
- Статистика по классу и отдельным ученикам
- Обнаружение подозрительной активности (переключение вкладок, копирование кода)

### Для учеников:
- Удобный редактор кода с подсветкой синтаксиса
- Таймер выполнения задания
- Автоматическое сохранение работы
- Блокировка при попытке переключения вкладок

## Технологии

- **Backend**: Python + Flask
- **Frontend**: HTML5, CSS3, JavaScript
- **База данных**: SQLite
- **Редактор кода**: CodeMirror

## Установка

1. Установите зависимости:
```bash
pip install flask flask-sqlalchemy flask-login
```

2. Запустите сервер:
```bash
python backend/app.py
```

3. Откройте в браузере: `http://localhost:5000`

## Защита от списывания

Платформа отслеживает:
- Переключение вкладок браузера
- Потерю фокуса окном
- Попытки копирования кода из внешних источников
- Время бездействия
- Подозрительно быстрое выполнение заданий

При обнаружении нарушений учитель получает уведомление, а нарушение фиксируется в журнале.
