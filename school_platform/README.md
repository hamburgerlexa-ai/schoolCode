# Образовательная платформа для проверки самостоятельных работ

Платформа для выполнения и проверки заданий по программированию с системой мониторинга подозрительной активности.

## Возможности

### Для учеников:
- Выполнение заданий по программированию прямо в браузере
- Встроенный редактор кода Python с подсветкой синтаксиса
- Автосохранение работы каждые 2 секунды
- Таймер времени выполнения
- **Система защиты от списывания:**
  - Отслеживание переключения вкладок
  - Фиксация потери фокуса окна
  - Блокировка инструментов разработчика (F12, Ctrl+Shift+I)
  - Предупреждения о подозрительной активности

### Для учителей:
- Панель управления со всеми заданиями
- Статистика по каждому заданию:
  - Количество сданных работ
  - Среднее количество переключений вкладок
  - Количество подозрительных отправок
- Детальный просмотр каждой работы с кодом ученика
- Информация о времени выполнения и подозрительной активности
- Экспорт всех работ в формате JSON
- Уведомления о подозрительной активности студентов

## Установка и запуск

### Требования
- Python 3.8 или выше
- Flask (устанавливается автоматически)

### Шаг 1: Перейдите в директорию проекта
```bash
cd /workspace/school_platform
```

### Шаг 2: Установите зависимости
```bash
pip install flask
```

### Шаг 3: Запустите сервер
```bash
python app.py
```

### Шаг 4: Откройте в браузере
Перейдите по адресу: **http://localhost:5000**

## Как это работает

1. **Ученик входит в систему** под своим логином и паролем
2. **Выбирает задание** из списка доступных
3. **Выполняет код** во встроенном редакторе
4. **Система отслеживает:**
   - Переключение на другие вкладки
   - Потерю фокуса окна браузера
   - Попытки использования инструментов разработчика
5. **Сохраняет работу** - код и статистика активности отправляются на сервер
6. **Учитель проверяет** работы в своей панели управления
7. **Подозрительные работы** помечаются красным индикатором

## Особенности системы безопасности

1. **Мониторинг вкладок**: Система фиксирует каждое переключение на другую вкладку
2. **Контроль фокуса**: Отслеживается потеря фокуса окном браузера
3. **Блокировка DevTools**: Запрещено использование F12 и других горячих клавиш
4. **Автосохранение**: Код сохраняется каждые 2 секунды в localStorage
5. **Логирование**: Все подозрительные действия записываются в базу данных

## Настройка

### Добавление новых пользователей
Откройте `app.py` и добавьте пользователя в функцию `init_db()`:
```python
students = [
    ('newuser', 'password', 'Фамилия Имя'),
    # ...
]
```

### Создание новых заданий
Добавьте задание в функцию `init_db()`:
```python
assignments = [
    ('Название', 'Описание', '# Шаблон кода', '2025-12-31'),
    # ...
]
```

## Примечания

- Платформа работает в локальной сети класса
- Все данные хранятся в базе данных SQLite
- Для продакшена рекомендуется использовать PostgreSQL и настроить HTTPS
- Система не блокирует переключение вкладок, а только фиксирует их
